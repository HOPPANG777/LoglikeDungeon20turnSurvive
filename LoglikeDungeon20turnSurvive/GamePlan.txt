## 로그라이크 던전 – 20턴 생존

### 1. 게임 개요

* **장르**: 턴제 로그라이크 던전
* **승리 조건**

  * 20턴 동안 생존 (턴 카운터가 20 이상이고 HP > 0)
  * 또는 보스 처치 (보스 등장 후)
* **패배 조건**

  * 플레이어 HP 0

---

## 2. 맵 구성

### 기본 설정

* 크기: **10 x 10 격자**
* 좌표 기반 2D 그리드

### 타일 표기 규칙

| 기호  | 의미        |
| --- | --------- |
| `P` | 플레이어      |
| `.` | 빈칸        |
| `#` | 벽 (통과 불가) |
| `M` | 몬스터       |
| `I` | 아이템       |
| `B` | 보스        |

※ 콘솔 환경이라면 `M`을 빨간색으로 출력 가능

---

## 3. 플레이어 기본 설정

초기 스탯 (구현 기준):

* HP 30 / ATK 4 / DEF 1
* 시작 위치 (1, 1)
* 포션 0개 (맵 `I` 타일에서 획득)

---

## 4. 입력 체계

| 키   | 동작              |
| --- | --------------- |
| W   | 위 이동            |
| A   | 왼쪽 이동           |
| S   | 아래 이동           |
| D   | 오른쪽 이동          |
| E   | 상호작용 (같은 칸 아이템 줍기, 포션 사용) |
| H   | 포션 사용 (체력 회복) |
| Q / ESC | 게임 종료           |

---

## 5. 턴 진행 구조

### 턴 루프 순서

1. 맵 + 상태 출력
2. 플레이어 입력 처리
3. 이동 결과 판정

   * 몬스터와 같은 칸 → 전투 발생 (이동은 하지 않음)
4. 몬스터 AI 이동 (플레이어 방향 1칸, 맨해튼 추적)
5. 몬스터가 플레이어와 같은 칸이 되면 전투
6. 턴 증가
7. 20턴 도달 시 보스 1회 등장 (아직 없을 때만)
8. 승패 판정

### 턴 소모 규칙

* Quit(종료)는 턴을 소모하지 않음
* 그 외 모든 입력(이동 실패, None 포함)은 턴 1회 소모

---

## 6. 전투 시스템

### 기본 규칙

* 자동 전투 1회 교환 방식
* 공격자 선공 → 방어자 생존 시 반격 1회
* 데미지: `max(1, 공격력 - 방어력)`
* 같은 칸에 머무르면 다음 턴에 다시 교환하지 않음 (이동/AI로 접촉할 때만)

### 몬스터 기본 스탯

* HP 8 / ATK 1 / DEF 1
* 시작 시 맵에 3마리 랜덤 스폰

### 보스 스탯

* HP 25 / ATK 3 / DEF 2
* 20턴에 맵 빈 칸에 1회 스폰

---

## 7. 몬스터 AI

* 플레이어와 x/y 차이 중 절대값이 큰 축으로 1칸 이동
* 벽·맵 밖·다른 몬스터 칸은 이동 불가
* 이동 후 플레이어와 같은 칸이면 전투 1회 교환

---

## 8. 아이템

* 맵에 `I` 타일 3개 고정 배치 (포션)
* 플레이어가 `I` 칸에 서서 `E` → 포션 +1, 타일 제거
* `H` 또는 `E`(아이템 없을 때) → 포션 1개 소비, HP +10 (최대 HP 초과 불가)

---

## 9. 승패 화면

* 승리: "Victory!" + 생존/보스 처치 사유
* 패배: "Defeat!" + HP 0
* 종료 후 아무 키나 입력 시 프로그램 종료
